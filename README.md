# 音声クリップ編集ツール

Windows 10 / 11向けの音声切り出しアプリです。Python / PySide6 / pyqtgraph / FFmpegを使用します。

## 主な機能

- MP3などの読み込み、ファイル・フォルダのドラッグ＆ドロップ、フォルダ再帰追加
- 波形の範囲選択、カーソル中心のズーム、横スクロール
- 選択部分だけ残す／削除、Undo／Redo、編集後の表示範囲維持
- 通常再生と選択範囲再生、ピッチを維持した0.5〜2倍速プレビュー
- 会話向けMossFormer2／音楽向けDemucsによるBGM処理、原音とのA/B比較
- WAV／MP3保存、連番保存、編集可能なタグ・ファイル名テンプレート

元ファイルは上書きしません。保存対象は現在選択しているA/Bの音声です。プレビュー速度は保存音声に影響しません。

## セットアップ

1. Python 3.12をインストールします。
2. 書き込み可能なフォルダにソースを配置し、`setup.bat`を実行します。
3. `run.bat`で起動します。

初回セットアップにはインターネット接続が必要です。FFmpegはimageio-ffmpeg経由で取得するため、通常は手動のPATH設定は不要です。

### BGM処理（任意）

- 会話向け（標準選択）: `setup_speech.bat`
- 音楽向け: `setup_bgm.bat`
- CPU専用で新規セットアップする場合: `setup_speech.bat cpu` または `setup_bgm.bat cpu`

専用環境`.venv-bgm`とモデルをダウンロードします。NVIDIA GPUが利用可能な場合はCUDAを使用できます。アプリでは自動／CPU／CUDAを選択できます。モデルと依存パッケージは同梱していません。外部パッケージ・モデルにはそれぞれのライセンス・利用条件が適用されます。

BGM処理の効果は素材によって異なります。処理後はA/Bで声の劣化を確認してください。

## 基本操作

音声を追加し、波形をドラッグして範囲を選択します。右クリックメニューから試聴・切り出し・削除・保存できます。

| 操作 | 初期ショートカット |
| --- | --- |
| 再生／一時停止 | Space |
| 選択範囲再生（終了後に開始位置へ戻る） | Shift＋Space |
| 通常速度／2倍速 | 1／2 |
| 5秒戻る／進む | ←／→ |
| 1秒戻る／進む | Ctrl＋←／→ |
| 元に戻す／やり直す | Ctrl＋Z／Ctrl＋Y |
| 保存 | Ctrl＋S |
| 選択解除 | Esc |
| 選択部分削除 | Delete |
| 拡大縮小／横移動 | Ctrl＋ホイール／Shift＋ホイール |
| 全体表示 | Ctrl＋0 |

設定画面でシーク秒数と速度切り替えキーを変更できます。再生速度は0.5／1.0／1.25／1.5／2.0倍から選び、次回起動時にも維持します。

## タグと保存

初期タグ:

- 音質: `clean`, `dirty`
- 演技: `normal`, `serious`, `soft`, `other`

デフォルト選択は`clean`／`normal`です。「設定…」から追加・名前変更・削除・並び替え・デフォルト設定ができます。

- **自動保存**: 指定フォルダへWAV / PCM 16bitで保存します。元のサンプルレート・チャンネル数を維持します。
- **手動保存**: 毎回名前と場所を指定します。WAV／MP3（320kbps）を選択できます。

自動保存の初期テンプレートは`{quality}_{acting}_{number}`です。`{source}`（元ファイル名・拡張子なし）も使用でき、連番桁数と次回番号を設定できます。`{number}`は必須です。連番はタグをまたいで進み、既存ファイルの番号を飛ばします。手動保存でも既存ファイルを上書きしません。

例: `clean_normal_0001.wav`、`dirty_soft_0002.wav`

設定はアプリフォルダの`settings.json`に保存します。このリポジトリには個人設定を含めていません。既存のsettings.jsonがある場合は保存済みのタグを優先します。初回のみ旧バージョンの保存先設定を引き継ぐ場合があります。


テストは一時的な合成PCMを使用します。配布用の実音声素材は不要です。通常の自動テストでBGMモデルの取得・推論は行いません。MP3変換・倍速テストにはFFmpegが必要です。
